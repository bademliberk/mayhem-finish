QUOTE MATH (integer; inferred from SDK 4.3.1; docs give no rounding rules; validate against real txs)
fee(x,bps) = ceil(x*bps/10000), protocol and creator separately.
Legacy buy, budget B: net = floor((B-1)*10000/(10000+p+c)); tokens = min(floor(net*vt/(vq+net)), real_token)
v3 exact-in: net = floor(B*10000/(10000+p+c)); if net+fees > B, net -= excess; tokens = floor((net-1)*vt/(vq+net-1)) capped at real_token
Buy cost for t tokens: net = floor(t*vq/(vt-t))+1; cost = net + fee_p(net) + fee_c(net)
Sell t: sol = floor(t*vq/(vt+t)); net = sol - fee_p(sol) - fee_c(sol)
Reserves: buy adds net to virtual+real quote, subtracts tokens from virtual+real token; sell reverses.
Buyback is a slice of protocol fee paid in-trade (none on Mayhem); buyer debit unchanged.
Buy exceeding remaining curve tokens crosses into a synthetic pool for non-Mayhem in v3: reject/cap in paper mode.

WIRE DECODING (web3.js 1.98.4)
- VersionedTransaction.deserialize: legacy and v0 only; others throw "Transaction message version N deserialization is not supported".
- v1 (SIMD-0385): byte 0x81 at offset 0, signatures at end, no ALTs, fixed-width counts, 4096-byte limit. Docs say enabled on mainnet/devnet/testnet; feature gate/slot unverified.
- Recommended: (1) bytes[0]===0x81 -> unsupported-v1 before deserialize; (2) VersionedTransaction.deserialize; (3) v0: connection.getAddressLookupTable(key) or AddressLookupTableAccount.deserialize, then message.getAccountKeys({addressLookupTableAccounts}); order static, lookup writable, lookup readonly; (4) missing/closed table or bad index -> unresolvable.
- v1/CPI/multi-swap options: skip+count (recommended for paper); custom v1 parser from SIMD; or fetch confirmed tx meta.innerInstructions.
- CPI/router swaps are invisible in raw wire data. Multiple Pump ixs in one tx can be applied sequentially.
